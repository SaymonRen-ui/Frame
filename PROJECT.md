# Frame Android — контекст для другого чата

## Что это
Локальная читалка манги и комиксов для Android в духе Mihon: библиотека
из папки на устройстве, категории, прогресс, история, читалка с настройками
в стиле Mihon. Аккаунтов и сети нет — только файлы на телефоне.

Цель: публикация в RuStore (бесплатное приложение с рекламой РСЯ, физлицо).

## Стек
- Kotlin 2.2.10, AGP 8.13.0, Gradle 9.3.0, compileSdk/targetSdk 36, minSdk 26
- Jetpack Compose + Material3, lifecycle-viewmodel, activity-compose,
  documentfile, material-icons; JUnit4 для тестов
- CBZ — свой разбор ZIP (`core/cbz/Cbz.kt`), PDF — штатный
  `android.graphics.pdf.PdfRenderer`, зависимостей ноль
- Пакет `com.saymon.frame`, versionCode 1 / versionName 0.1.0, APK `Frame.apk`

## Что сделано
- Библиотека из папки: SAF tree URI (Android 11+) или `/sdcard/Frame`
  (Android 10 и ниже), выбор запоминается в SharedPreferences
- CBZ/PDF: обложки (из архива, `cover.jpg` или первая страница), главы,
  счётчики страниц, компактная сетка, поиск, сортировка
- Категории-вкладки (по умолчанию «Читаю / В планах / Закончил / Брошено /
  Избранное»), горизонтальная прокрутка чипов с индикатором
- Экран произведения: автор, описание, рейтинг, отзыв, избранное,
  массовые действия с главами, удаление с очисткой следов
- Прогресс по главам, история последних 50 записей, миниатюры, удаление
- Читалка: 6 режимов (в т.ч. RTL и длинные страницы), ориентация,
  5 схем зон касания, двойное нажатие, фон, счётчик страниц, fullscreen,
  «не гасить экран», автоудаление прочитанного
- Меню чтения снизу: тянется пальцем 1:1, закрывается у нижней границы
  или стрелкой назад, сбрасывается при открытии
- Проверка целостности глав, удаление битых, очистка кэша
- Бэкап/восстановление настроек, прогресса и истории в JSON
  (`library_uri` в бэкап не попадает — доступ привязан к устройству)
- Тема: системная/светлая/тёмная, edge-to-edge, иконки системных панелей под тему
- Реклама РСЯ: баннер в библиотеке и истории (над панелью навигации),
  interstitial при выходе с экрана произведения, кулдаун 5 минут

## Грабли (чтобы не наступать снова)
- РСЯ не отдаёт рекламу дебажным сборкам: реальный показ — только релиз.
  `YandexAds.setAgeRestricted(true)` ломает загрузку (`code=4 NO_FILL`),
  для 0+ достаточно `setUserConsent(false)`.
- `Scaffold` + `contentWindowInsets` + `TopAppBar.windowInsets` легко дают
  двойной верхний отступ: на экранах вкладок оба выставлены в 0, отступ
  сверху даёт только системный статус-бар.
- Баннер нельзя класть внутрь `NavigationBar`: он должен быть отдельным
  блоком над ним, с `navigationBarsPadding()` и буферной зоной.
- `MANAGE_EXTERNAL_STORAGE` не используется: RuStore не любит, SAF достаточно.

## Структура
- `app/src/main/.../MainActivity.kt` — вкладки, нижняя панель с баннером, роутинг экранов
- `ui/LibraryScreen.kt`, `ui/TitleScreen.kt`, `ui/HistoryScreen.kt`,
  `ui/ReaderScreen.kt`, `ui/SettingsScreen.kt` — экраны
- `ui/LibraryViewModel.kt` — состояние, SAF, сканирование, кэш, проверка целостности
- `data/Store.kt` — SharedPreferences + JSON: вкладки, прогресс, история, настройки, бэкап
- `data/Library.kt` — модель произведения, главы, обложки
- `core/cbz/Cbz.kt` — чтение ZIP, страницы, кэш распакованных глав
- `core/ads/AdManager.kt`, `core/ads/BannerAd.kt` — РСЯ
- `store/` — иконка 512×512 и тестовый CBZ
