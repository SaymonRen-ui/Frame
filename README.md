# Frame — читалка манги и комиксов (CBZ / PDF)

Локальная читалка для Android в духе Mihon: библиотека из папки на устройстве,
категории, прогресс, история и гибкие настройки чтения. Без аккаунтов, облака
и сетевых запросов — все файлы остаются на телефоне.

## Возможности

- Библиотека из любой папки через SAF (Android 11+) или `/sdcard/Frame`
  на Android 10 и ниже; доступ выдаётся один раз и запоминается
- Форматы CBZ и PDF, обложки из архива или отдельного файла
- Категории (вкладки) с прокруткой, поиск, сортировка, компактная сетка,
  счётчик непрочитанных глав
- Экран произведения: автор, описание, рейтинг, отзыв, избранное;
  массовые действия с главами (прочитано, избранное, удаление)
- Прогресс чтения по каждой главе, история последних 50 записей
  с миниатюрами, удаление отдельных записей и очистка истории
- Читалка: шесть режимов (постранично, справа налево, вертикально,
  длинные страницы), ориентация, зоны касания, двойное нажатие для
  увеличения, фон, счётчик страниц, полноэкранный режим, «не гасить экран»
- Меню чтения в стиле Mihon: выдвигается снизу, тянется пальцем,
  закрывается свайпом вниз или стрелкой назад
- Удаление главы после прочтения, автоматическая очистка кэша
- Проверка глав на целостность (битые CBZ/PDF) с отчётом
- Резервная копия настроек, прогресса и истории в JSON и восстановление
- Тёмная/светлая тема или как в системе

## Сборка

Открыть папку в Android Studio и нажать Run, либо из командной строки:

```
.\gradlew.bat :app:assembleDebug      # отладка
.\gradlew.bat :app:assembleRelease    # релиз (нужен ключ, см. ниже)
.\gradlew.bat :app:bundleRelease      # AAB для стора
```

Требования: JDK 17, Android SDK (compileSdk 36, minSdk 26).
Готовый файл: `app/build/outputs/apk/debug/Frame.apk`.

### Релизная подпись

Ключ `frame-release.jks` и пароли в `local.properties` не коммитятся
(см. `.gitignore`). Потеря ключа = невозможность обновлять приложение в сторе,
бэкап обязателен.

## Монетизация

Реклама Рекламной сети Яндекса (РСЯ):

- баннер внизу экранов «Библиотека» и «История» — над панелью навигации,
  не перекрывает контент и не показывается в читалке;
- один interstitial при закрытии главы — при выходе из читалки в список глав.

ID блоков — `core/ads/AdManager.kt`.

Важно: сервер РСЯ не отдаёт рекламу дебажным сборкам (`code=3`, network
error) — показ проверяется только на релизной сборке, подписанной
`frame-release.jks`. Не вызывайте `YandexAds.setAgeRestricted(true)`:
с ним реклама не грузится (`code=4 NO_FILL`), для 0+ достаточно
`setUserConsent(false)`.
